Build a complete production-ready school examination platform called:

MPPS MCQ Tester

MP Public School, Mathuranagar

Technology Requirements:

- Next.js
- TypeScript
- Tailwind CSS
- Firebase Authentication

CORE RULE

This platform supports ONLY MCQ examinations.

Do NOT implement:

- Subjective Questions
- Essay Questions
- Descriptive Questions
- Student File Uploads
- Assignment Submission System

Only Multiple Choice Question (MCQ) tests are allowed.

Remove all production dependency on localStorage.

Use:

- Firebase Authentication
- Firebase Firestore
- Firebase Storage

Store permanently:

- Students
- Teachers
- Tests
- Questions
- Student Attempts
- Results
- Notices
- Rankings
- Analytics
- Violation Records

Data must:

- Persist after refresh
- Persist after logout/login
- Persist across devices
- Persist after deployment

Teacher-created tests must be visible to students.

Principal notices must be visible to students.

Student results must remain permanently stored.

Do not use localStorage for critical data.

Use Firestore real-time listeners wherever appropriate.
